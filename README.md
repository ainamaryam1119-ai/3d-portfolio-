# Aina Liaqat — 3D AI Portfolio

A responsive, dark-blue portfolio with an interactive Three.js neural sphere, animated reveal effects, project cards, and contact links.

## Preview locally
1. Download and extract this project.
2. Open `index.html` in a modern browser.
3. Keep an internet connection available for Google Fonts and the Three.js CDN.

## Customize before publishing
Open `index.html` and search for:
- `your.email@example.com` — replace with your real email address.
- `https://www.linkedin.com/` — replace with your LinkedIn profile URL.
- `https://github.com/` — replace with your GitHub profile URL.
- Project descriptions — replace concept descriptions with your actual project details and demo links.

## Publish with GitHub Pages
1. Create a new public GitHub repository, for example `aina-portfolio`.
2. Upload `index.html` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish your site. Your public URL will appear in the Pages section.

## Notes
- The 3D scene uses Three.js from cdnjs, so the first load needs internet access.
- The layout adapts to phones, tablets, and desktop screens.
- The 3D animation respects reduced-motion preferences only for CSS transitions; the 3D scene remains subtle.


## Motion effects
- Animated typewriter headline
- Responsive particle-and-connection background
- Continuously scrolling expertise ticker
- Subtle 3D hover tilt on project and skill cards
- Reduced-motion accessibility support
